Senior Thesis / Capstone Project (Report A) — BME 129C, Spring 2026

Briefly describe what problem you were solving

This report investigates whether living systems — from gene regulatory networks to cross-species gene exchange — operate as decentralized economies rather than centrally controlled machines. The project applies Austrian economic theory (Hayek, Mises, Menger) to biological data at three scales: network topology analysis of E. coli and S. cerevisiae regulatory, metabolic, and protein interaction networks; agent-based economic modeling of metabolic pathways; and cross-species gene transferability mapping across eight organisms from four kingdoms.

The work demonstrates quantitatively that distributed biological architectures outperform centralized alternatives by a 19:1 robustness ratio, with direct implications for how synthetic biologists should design genetic systems — as economies, not machines.

I chose this problem myself, drawing on my prior work building the Adaptive Genome Design System and my independent study of Austrian economics and biological coordination. The project was developed with guidance from my advisor, R. Dubois.

What you had to learn beyond formal coursework

This project required me to learn Austrian economic theory (Hayek's knowledge problem, Mises' economic calculation problem, Menger's spontaneous order) and translate those frameworks into testable biological hypotheses. I taught myself network science (scale-free topology, motif analysis, robustness simulation), single-cell RNA sequencing analysis using Scanpy, agent-based economic simulation, genome-scale flux balance analysis with COBRApy (iML1515 model), and cancer genomics analysis using TCGA PanCancerAtlas data.

I also had to learn how to retrieve and integrate data from multiple biological databases (RegulonDB, KEGG, STRING, CellxGene) into a unified computational pipeline.

Your contribution to the project

I am the sole author and developer. I designed the research question, developed the three-layer analytical framework, wrote all computational code (Python — NetworkX, Scanpy, COBRApy, custom agent-based simulations), retrieved and processed all biological datasets, generated all figures, and wrote the full capstone paper. My advisor R. Dubois provided guidance on capstone structure and presentation.

Class Project Report (Report B) — BME 230A: Computational Genomics, Winter 2025

Briefly describe what problem you were solving

This project involved computational analysis of single-cell RNA sequencing data to address two core bioinformatics challenges: (1) detecting and removing technical doublets from scRNA-seq libraries using Bayesian nearest-neighbor scoring, and (2) constructing weighted gene co-expression networks (WGCNA) to identify co-regulated gene modules and hub genes.

Using mouse scRNA-seq data (GEO: GSE186078, Illumina NovaSeq 6000), I implemented doublet simulation by summing randomly chosen transcriptomes, KNN-based doublet scoring with Bayesian estimation and standard error computation, and threshold-based filtering at multiple percentiles (90th, 95th, 99th). I then built gene co-expression networks using Pearson correlation, soft-thresholding power optimization, Topological Overlap Matrices (TOM), and hierarchical clustering to identify gene modules across CD4 and CD8 T cell populations.

Additional coursework included count distribution modeling — fitting Poisson and negative binomial distributions via maximum likelihood estimation to InDrops negative control data (Klein et al. 2015) to characterize technical vs. biological zeros in UMI count matrices.

The problems were assigned by the instructor as part of BME 230A: Computational Genomics. This topic demonstrates my engineering abilities in computational pipeline development, statistical modeling of high-dimensional biological data, and network analysis applied to real genomic datasets.

What you had to learn beyond formal coursework

This project required me to learn the mathematics of doublet detection in droplet-based scRNA-seq — Poisson loading models for microfluidic encapsulation, Bayesian doublet scoring formulas with nearest-neighbor classification, and standard error estimation for doublet likelihood scores. I also learned weighted gene co-expression network analysis (WGCNA), including soft-thresholding power selection for scale-free topology, Topological Overlap Measures (TOM), and hierarchical module detection with dendrogram cutting.

I had to become proficient with Scanpy, AnnData, and the h5ad data format for single-cell analysis, as well as maximum likelihood estimation for negative binomial count distributions using L-BFGS-B optimization applied to UMI count matrices. The WGCNA analysis additionally required learning Pearson correlation-based adjacency construction, clustering coefficient computation, and pathway enrichment testing for identified gene modules.

Your contribution to the project

I am the sole author of all submitted work. I implemented all computational analyses in Python (NumPy, SciPy, Scanpy, scikit-learn, NetworkX, matplotlib), wrote the doublet detection pipeline from the mathematical formulations provided in the assignment, built the WGCNA pipeline including correlation matrices, soft-thresholded adjacency computation, TOM calculation, and hierarchical clustering with module identification, and completed all count distribution modeling problems with MLE parameter fitting for Poisson and negative binomial models.
