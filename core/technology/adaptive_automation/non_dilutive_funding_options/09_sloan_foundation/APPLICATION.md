**Amount:** $50K–$500K (varies by project)
**Equity/IP:** None. Non-dilutive.
**Deadline:** No fixed deadline — proposals accepted on rolling basis via program officer contact
**Time to apply:** ~5-8 hours (Letter of Inquiry + full proposal if invited)

---

## When to Apply

The Sloan Foundation's "Open Source in Science" program funds the
**infrastructure, institutions, and economic models** around open research
software. Unlike CZI EOSS (which funds software directly), Sloan is
interested in the sustainability and ecosystem questions.

**Strategy:** Apply after you have:
1. A working open-source tool with some users
2. A clear sustainability model (the Red Hat / open-core approach)
3. Evidence of community forming around the tool

**Realistic timeline:** Late 2026 or 2027. This is a Tier 2 opportunity.

---

## What They Fund

The program specifically supports:
- **Economic models** for sustaining open-source scientific software
- **Institutional infrastructure** around open research tools
- **Community development** in open science ecosystems
- **Research** on how open-source software impacts science

They are interested in the **meta-question**: how do you build sustainable
open-source tools for science? The Red Hat model (open core + commercial
platform) is exactly the kind of economic model they study.

## Letter of Inquiry (Draft — for when ready)

### Project Title
Sustainable Open-Source Infrastructure for Organism-Scale Biodesign

### The Problem

The design tools for biological systems are being built by proprietary
companies (Ginkgo Bioworks, Zymergen successors, defense-adjacent synthetic
biology firms). If organism-scale design — the ability to specify biological
function in English and receive synthesizable DNA — becomes locked behind
platform licenses, only well-funded institutions will shape the biological
future.

The open-source scientific software ecosystem has mature tools for sequence
analysis (BLAST, Bioconductor), gene expression (DESeq2, Scanpy), and
protein structure prediction (AlphaFold tools). But there is no open-source
tool that integrates these layers into an organism-scale design system.

### The Proposal

LivingCAD is building this missing layer as open-source infrastructure,
sustained by a commercial platform (Red Hat model):

- **Open core:** Compatibility engine, GRN database, bridge layer — free,
  open-source, installable via pip
- **Commercial platform:** Full pipeline with GUI, wet lab integration,
  priority support — subscription-based ($50-2,000/month)

This grant would fund research and documentation of this economic model
as it develops, providing a case study in sustainable open-source scientific
software for the biological design space.

### What already exists
- Genome retrieval: 220+ genomes
- Codon optimization: 5 chassis organisms, validated RSCU tables
- Regulatory compatibility: 24 characterized parts, 5 organism classes
- Pathway conflict detection: 12 metabolic profiles
- Claude API integration for English → biological specs

### What the grant would fund
1. **Economic sustainability research:** Document the open-core model for
   biological design software as it scales from 0 to 100+ users
2. **Community infrastructure:** Documentation, contributor guides, governance
   model for the open-source components
3. **Packaging and distribution:** Make the open core installable and
   interoperable with the scientific Python ecosystem
4. **A published report** on the economics of open-source organism-scale
   biodesign tools

### Budget estimate
$75,000–$150,000 over 18 months

## How to Apply

The Sloan Foundation does NOT have a standard application form. The process:

1. **Identify the program officer** for "Open Source in Science" or
   "Digital Technology" at https://sloan.org/programs/digital-technology
2. **Send a Letter of Inquiry** (1-2 pages) via email to the program officer
3. **If invited:** Submit a full proposal (5-15 pages) with budget justification
4. **Review period:** Several months typically
