# Outreach Pipeline — California LC Network

> Mycelium doesn't reach every root at once. It grows toward what's alive.

---

## How This Works

Every contact moves through **five stages**. You only actively work on people in the first three stages. Once someone is Active or an LC, they sustain themselves — you just stay connected.

**Your rule: never have more than 10 people in "Reaching Out" at once.** That's your carrying capacity. When one moves forward (or gets pruned), you pull the next one from the queue.

| | | | | | | |
| | | | | | | |

**Vibe Check key:**
- `Resonant` — They get it. Spiral language clicks. Potential LC
- `Friendly` — Positive but not deeply engaged yet. Keep watering
- `Institutional` — Doing it for the resume. Fine for events, not LC material
- `Uncertain` — Need more conversation to read

**Rules:**
- Ask: "What's working? What's dead? What do you need?" — don't pitch
- If they light up about ideas (not just logistics), note them as Resonant
- Move to Active when they've done *something* — attended an event, tabled, shared a resource
- Follow up within 7 days of last contact. If you let it go 14+, the thread dies
