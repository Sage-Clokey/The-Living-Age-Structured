## Application Narrative

### Company/Project Name
The Living Age / LivingCAD

### One-Line Description
Open-source biodesign software that translates English into organism-level
DNA designs for structural biology and living architecture.

### Problem
The $10 trillion global construction industry is built entirely on dead
materials — concrete, steel, glass — that degrade from the moment they're
installed. Living organisms already produce stronger, self-repairing materials.
The design tools to engineer these organisms don't exist.

### Solution
LivingCAD is an organism-scale biodesign platform. Users describe desired
biological function in English. The system interprets intent (via Claude LLM),
generates candidate proteins (via ESM-3), optimizes DNA for target organisms,
validates against compatibility constraints, and explains results in English.

### Traction / What Exists
Working codebase (not a pitch deck):
- Genome retrieval system: 220+ genomes from UCSC and NCBI
- Codon optimization engine: validated RSCU tables for 5 chassis organisms
- Regulatory element compatibility analysis: 24 characterized parts
- Pathway conflict detection: 12 metabolic/signaling profiles
- Adaptive assembly engine
- Claude API integration for English → biological specification

### Market
