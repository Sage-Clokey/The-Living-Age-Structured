Which report best reflects concern for global, social, or environmental issues?

Report A The project argues that synthetic biology's dominant command-and-control approach — centrally engineering every genetic component — is structurally fragile and wasteful. By demonstrating that distributed biological architectures outperform centralized alternatives by a 19:1 robustness ratio, the work provides a framework for designing more resilient, sustainable engineered biological systems. This has direct implications for sustainable materials, biomanufacturing, and agricultural biotechnology — fields where robust, self-correcting genetic designs could reduce resource waste and environmental impact.

Please provide a list of the tools and techniques you used to produce your projects

Report A For Report A (BME 129C Capstone), I used Python (NetworkX, Scanpy, COBRApy, NumPy, SciPy, matplotlib) for all computational analysis. Network topology analysis used RegulonDB, KEGG REST API, and STRING database for biological network construction, with custom robustness simulation and motif analysis (triadic census against 1,000 randomized networks). Single-cell analysis used Scanpy with pre-processed PBMC data from CellxGene in h5ad/AnnData format. Metabolic modeling used a custom agent-based economic simulation and genome-scale flux balance analysis with COBRApy on the iML1515 E. coli model (2,712 reactions, 1,877 metabolites). Cancer genomics analysis used TCGA PanCancerAtlas data via cBioPortal. Cross-species trade mapping used codon usage tables from the Kazusa database and gene sequences from UCSC Genome Browser and NCBI Entrez. Figures were generated with matplotlib and presentations built in PowerPoint.

Report B For Report B (BME 230A Computational Genomics), I used Python (NumPy, SciPy, Scanpy, scikit-learn, NetworkX, matplotlib) in Jupyter notebooks. Doublet detection used KNN classification (scikit-learn NearestNeighbors), Bayesian scoring, and UMAP visualization via Scanpy on mouse scRNA-seq data (GEO: GSE186078, AnnData/h5ad format). Gene co-expression network analysis (WGCNA) used Pearson correlation, soft-thresholding power optimization, Topological Overlap Matrix computation, and hierarchical clustering (SciPy linkage/dendrogram). Count distribution modeling used maximum likelihood estimation with L-BFGS-B optimization (SciPy) to fit Poisson and negative binomial models to InDrops UMI count data.
